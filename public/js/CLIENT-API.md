# Client-API für Oberflächen-Module (public/js/ui/*.js)

Vanilla JS, ES-Module, keine Bibliotheken. Alles Deutsch. Pixel-Stil über `style.css` (Klassen `.pix`, `.knopf`, `.knopf.gold|.rot|.gruen|.klein`, `.eintrag`, `.karte-liste`, `.tabelle`, `.reiter`, `.balken`, `.klein`, `.gold-t|.gruen-t|.rot-t|.blau-t|.lila-t`).
Eigene CSS-Regeln: in einem `<style>`-Element, das dein Modul einmalig in `document.head` einfügt (Präfix mit deinem Modulnamen).

## Bausteine
- `ui/basis.js`: `el(tag, attr, ...kinder)` (tag wie `'div.klasse#id'`, attr: `text`, `html`, `onclick`, `tip` (Tooltip-Text oder Funktion), `style` (Objekt), sonstige Attribute), `symbol(kategorie, id, {farbe, zeitalter, variante, groesse, px})` → Canvas mit Pixel-Sprite, `fenster(titel, (inhalt, f) => {...}, {breite: 'schmal'|'mittel'|'voll', fuss: true, modal, beiSchliessen})` → `{schliessen(), inhalt, fuss, element}`, `frageJaNein(titel, text, jaText)` → Promise<bool>, `toast(text, art('info'|'erfolg'|'warnung'|'fehler'), {symbol, onclick})`, `fehler(text)`, `zahl(x, stellen)`, `vorzeichen(x)`, `dauerText(ms)`, `uhrzeit(t)`, `balken(anteil, 'blau'|'gold'|'rot'|'')`, `alleFensterZu()`.
- Sprite-Kategorien (`symbol(...)`): `einheit` (id = Einheiten-ID, mit `farbe`), `gebaeude`, `wunder` (64x64), `verbesserung` (48x32), `rohstoff` (16x16), `ui` (16x16: gold, holz, stein, ..., nahrung, produktion, wissenschaft, kultur, zufriedenheit, unzufrieden, bevoelkerung, staerke, fernkampf, reichweite, tempo, sicht, hp, zeit, krieg, frieden, handel, diplomatie, forschung, bau, stadt, einheit, rangliste, einstellungen, hilfe, lexikon, meldung, schliessen, ton_an, ton_aus, karte, zeitalter, wunder, befoerderung, schlafen, befestigen, erkunden, arbeiten, angriff, bewegen, aufloesen, aufruesten, gruenden, pluendern, atom, luft, see, schild, warnung, haken, kreuz, plus, minus, pfeil_links, pfeil_rechts, menue, auge_zu, stern_voll, stern_leer, krone, nacht, tag, regen, schnee, uhr, gift, lager, offene_grenzen, buendnis, tribut, forschungsabkommen, karte_tausch), `zweig` (Forschungszweige: wirtschaft, militaer, see, wissen, staat, industrie, luft, raumfahrt), `stadt` ('stadt' mit zeitalter 0..6 und groesse 1..3; 'stadtstaat'), `deko` (Gelände-ID, variante 0..3), `tier`.
- `kern/zustand.js`: `Z` (Z.ansicht = Server-Ansicht, Z.volk = eigene Volk-ID, Z.demo), `an(ereignis, fn)` ('aenderung' {gruppen:Set|voll}, 'meldungen', 'kampf'), `du()` (eigenes Volk: gold, lager, raten{gold, einnahmen, unterhaltEinheiten, unterhaltGebaeude, handel, wissenschaft, kultur, material, kapazitaet, luxus, boni}, forschung{aktiv, fortschritt, fertig_um, schlange, erforscht, teil, dauer_ms}, zeitalter, schutz_bis, meldungen, tutorial, einstellungen, routen, routenKapazitaet ...), `volk(id)` (name, farbe, art 'spieler'|'ki'|'stadtstaat'|'barbar'|'tiere', zeitalter, bekannt, online, angreifbar, schutz_bis; Stadtstaaten: einfluss, verbuendet, vorlage; KI: persoenlichkeit, herrscher, stimmung), `stadt(id)` (eigene: bev, nahrung, bedarf, kultur, grenzkosten, gebaeude[], bau[{art,id,start,fertig_um}], schlange[{art,id}], arbeit[], gebiet[], manuell, hp, maxhp, staerke, raten{n,p,g,w,k,material,verbrauch,ueberschuss,zufriedenheit,grenzKultur,unterhalt}, wachstum_um, grenze_um, bauplaetze, mauer, kueste), `einheit(id)`, `eigeneStaedte()`, `eigeneEinheiten()`, `aktuellesGold()`, `aktuellesLager(gut)`, `forschungsFortschritt()`, `serverJetzt()`. `Z.ansicht.diplomatie[volkId]` = {krieg, seit, letzter_kampf, offene_grenzen, buendnis}, `Z.ansicht.angebote` (id → {id, von, an, art, gibt, will, auto, parteien, zustimmung, kosten}), `Z.ansicht.wunder` (id → {volk, stadt, fertig}), `Z.ansicht.welt` (im_bau [{wunder, volk}], jahreszeit, ereignisse, tribute).
- `kern/netz.js`: `befehl({art, ...})` → Promise<{ok, fehler?, ...}> (Fehler mit `fehler(r.fehler)` anzeigen). `frage({art, ...})` → Promise<daten> (wirft Error mit Text).
- Befehle (Server prüft alles): `bauen {stadt, typ:'gebaeude'|'einheit'|'wunder', id, vormerken?, geheim?}`, `bau_abbrechen {stadt, liste:'bau'|'schlange', nr}`, `bau_hoch {stadt, nr}`, `forschen {id}` (setzt fehlende Voraussetzungen automatisch davor), `forschung_schlange {ids}`, `feld_bewirtschaften {stadt, feld, an}`, `auto_bewirtschaften {stadt}`, `stadt_umbenennen {stadt, name}`, `krieg_erklaeren {volk, bestaetigt}`, `diplomatie_angebot {an, typ:'frieden'|'offene_grenzen'|'buendnis'|'forschungsabkommen'}`, `angebot_antwort {id, annehmen}`, `angebot_zurueckziehen {id}`, `tausch_angebot {an, gibt:{gold, lager:{gut:n}, luxus:[id], karte}, will:{...}}`, `tribut_fordern {an}`, `stadtstaat_geschenk {stadtstaat, gold}`, `tutorial {schritt, fertig}`, `einstellungen {werte:{ton, musik, lautstaerke, tagnacht, wetter}}`, `neuanfang`.
- Fragen: `bauliste {stadt, alle?}` → {liste:[{art, id, grund|null, kosten, fehlt|null, dauer(ms)}]}, `rangliste` → {spieler:[...], ki:[...]} je {id, name, farbe, zeitalter, online, gold, militaer, staedte, bevoelkerung, forschungen, gebiet, kultur, wunder, gesamt}.
- Daten: `../../shared/daten/index.js` (FORSCHUNGEN, FORSCHUNG, EINHEITEN, EINHEIT, GEBAEUDE, GEB, WUNDER, WUNDER_NACH_ID, BEFOERDERUNGEN, ROHSTOFFE, ROHSTOFF, VERBESSERUNGEN, VERBESSERUNG, GELAENDE, KI_VOELKER, STADTSTAATEN, BARBARENLAGER, ZEITALTER, FREIGESCHALTET_DURCH ('art:id' → Forschungs-ID), NACHFOLGER, STARTFORSCHUNGEN), `../../shared/regeln.js` (Formeln/Konstanten), `../../shared/daten/rohstoffe.js` (LAGER_NAMEN, LAGERGUETER).
- Weitere Helfer: `ui/hud.js`: `springe(feld)` (Kamera hin), `waehle({art:'einheit'|'stadt'|'feld', id})`, `bauName(b)`; `ui/fenster.js`: `forschung(id)`, `stadt(id, reiter)`, `reich()`, `diplomatie(volkId)`, `rangliste()`, `lexikon(art, id)`, `hilfe()`, `einstellungen()`, `tutorialEreignis(art, daten)`; `audio.js`: `ton(art)`.
- Texte der Oberfläche gehören nach `js/texte.js` (Objekt T); ergänze dort einen eigenen Unterschlüssel für dein Modul.
- Bedienung: PC (Maus/Tastatur) und Tablet (Touch, große Trefferflächen ≥ 38px, nichts nur per Hover). Esc schließt Fenster (macht basis.js).
- Prüfen: `node tools/foto.mjs '/?demo=1' <aus.png> 1600 900 9000 "<js, das z. B. dein Fenster öffnet>"` macht einen Screenshot des Demo-Modus (Engine läuft im Browser, `window.__demo.spiel` ist die Engine) und meldet Konsolenfehler. Auch mit 1024x768 (Tablet) prüfen. Ansehen mit dem Read-Tool.
